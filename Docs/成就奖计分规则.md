# 高三最高成就奖 · 计分规则（已确认）

> 适用版本：Achievement-Award-Viewer v1.3.4（2026-09-28 更新）。
> 这份是「规则说明」：给上级、老师核对用。规则的**实际设定**在 `config/` 的 JSON 文件里（见第一节），改 JSON 就会改变计算；改这份文件不会。
> 每次规则有变，请同时更新这份文件（写明「上级定」「维护者定」和日期）。

## 一、工具与规则文件

- 资料来源：`Result/`（每位学生一份「联课活动个人表现履历表」，.xlsx / .pdf）。Result 里只有年份子文件夹（例：`Result/2025`、`Result/2026`）时，网站读最新一届。
- 运行：`python app.py` 或双击 `Achievement-Award-Viewer.exe` → 浏览器自动打开；Result 或规则文件有变动，网页几秒内自动重算。
- 规则文件（都在 `config/`，存档后自动生效；exe 版把改好的文件放在 exe 旁边的 `config\` 会优先采用）：

| 文件 | 管什么 |
|---|---|
| `member_rules.json` | 执委 / 职务归类：执委、主席级、中层管理、会员；执委栏 ↔ 筹委栏移动；不计的内容；★ 特别标记 |
| `award.json` | 比赛：算不算获奖 ★、是不是代表本学会 |
| `work.json` | 资料总览「活动/工作/比赛」里的「工作」：哪些栏目算、哪些是例常不算、活动栏哪些改算工作、同一类合并 |
| `config.ini` | 网站设定、资料总览的年份栏 |

- 其它流程（服务时数、B 类、双学会重复、拆句）在 `achievement/rules.py`；网页端即时重算在 `static/core.js`，两边要一致。
- 手动「计入 / 不计」：个人页每条右边的按钮，自动存在 `data/成就奖_手动调整.json`，所有数字（含资料总览、Excel）都会套用。
- 参考清单：网页右上角「下载职位一览」「下载获奖一览」（或 `--list-roles` / `--list-awards`），列出所有职位 / 比赛条目目前被怎么判断，方便校对。

## 二、计入范围（不计的内容）

不计的条目在个人页「详细」以灰色划线显示并注明原因，所有数字都不含它们。

1. 以班级为单位的内容、服务、活动、比赛不计（班级身份参赛、班级表演、班级赛服务、班级监督等；含「心动不如Sing动」「开启你的Music Show」等班级歌曲比赛；上级定：「运动会写生比赛」「运动会号码布设计比赛」「运动会短片制作比赛」也属班级活动）。
2. 学会的筹委、团内工作照算（例：合唱团筹办班级歌曲合唱比赛的票务股；团内工作中的班级赛工作人员）。
3. 只计 A、C、D、E 类；B 类（体育、学术培训队）整年不计。
4. 高三毕联会 / 高三年级组的职位与筹委属于年级，不计（如「高三毕联会广告工委」「毕业班联合会之谢师宴筹委正秘书」）；编辑工委会、广告工委会、教师节工委会即使没写「毕联会」也按毕联会处理。一条里同时写了学会职位和毕联会职位时，只划掉毕联会那部分。毕联会相关的服务时数、活动照算（如高中毕业典礼服务、高三欢送会工作）。
5. 上级定：感恩聚会不算学会活动，各栏相关条目全部不计，服务时数一并扣除。
6. 上级定：学会在运动会上的义卖不计（各栏都不计，服务时数一并扣除）；学会在运动会上的演出、表演和服务照算。
7. 上级定：教师节相关的「校内服务」不计（服务时数一并扣除）；其它栏目里的教师节条目照原规则。
8. 上级定：荣获模范学长、教师节演出·负责人不算职位；编辑小组《校讯》每一期的主编 / 副主编不算。

## 三、执委 / 职务、中层管理、会员

**标准写法**（上级 2026-09-24 校对）

- 标准职称：主席、秘书、事务（「事物」「总务」同一等级，一律写成「事务」）、财政（正/副）、查账（不分正副）、总学长（正/副）、助理总学长、执委。
- 其它职位一律写成「执委(XXX,XXX)」，计入其中的职位个数；有上下文的写成例如「执委(联课处工委联课表扬大会-事务(副))」。
- 主席 / 秘书 / 事务 / 财政 / 总学长没写正/副 → 当作「正」（做法 A）。
- 主席级（写成「主席(正/副)」）：合唱团「音乐主席」、二十四节令鼓队的队长类、例常活动主席（例常活动副主席 = 主席(副)）。
- 联课处工委归入执委(…) 并计入职务数（另有 ★ 特别标记）。

**中层管理**（另计「中层管理数」＝该年不同中层管理职位的个数，不算进职务数）

- 助理类；授课人类（助教、小教练、教官/副教）；队长类（正/副队长、队副、小队副、分团总队长、小队长 / 中队长 / 分队长等；节令鼓队长仍算主席）；监督 / 督导 / 顾问 / 教练 / 领队类；首席 / 组长 / 领养人类（副弹拨首席、扬琴组长、扬琴组领养人、声部组长、小组组长……）；家族职位（家族家长、家族卫生、家族团康、家族族长）；联课组别（联课组别第六组）。
- 校内服务负责人（维护者定，取代先前「属于筹委」的说法）：「校内服务负责人：新春快闪、运动会开幕及闭幕仪式演出」拆开，每项各算 1 个。
- 上级 2026-09-25 定：学长团「小队正/副常委」、救伤队「体能关主 / 口令员」、武术团「堂主」。
- 上级定：制服负责人、课务股、总部区域性急救与步操比赛队伍管理、师徒制度·师傅。
- 一条里同时有中层管理和其它职位（如「正课程+小教练」「主席助理兼正纪律」）时拆开各自计算。

**会员**（不计职务数；同年已有其它职位时不另列会员）

- 童军等「分团」职位（队长类除外）；学警职衔（Koperal / Lans Koperal / Sarjan）；各种「XX培训 / 培训人员」；「实习学长」；单写「学长」。

**执委栏 ↔ 筹委栏**（页面会标「原写在执委栏 / 筹委栏」）

- 移到筹委（不计职务数）：为某个活动组成的筹委团职位（「《弈德杯》筹委主席」「欢送会正主席」「开放日-负责人」）；「监督XX主席」「督导XXX主席」；运动会、田径赛的筹委 / 职位（服务筹委团；班级名义的仍不计）；写在执委栏的演出（演员、演奏员、演唱者等）和公演的工委 / 带领人；写了工作时数的活动职位（联课处工委写了时数的照算执委）；交流志工团职位（上级定：台湾永平高中与循中交流志工团·副主席）。
- 一格里连写「执委主席监督成果汇报主席监督…主席」的会拆开，执委主席照算职务。
- 移到执委栏：写在筹委栏的监督 / 督导 / 顾问 / 教练 / 领队类（按上面的规定算中层管理）；「监督 / 督导XX主席」则留在筹委。

**★ 特别标记**（只做标记，不改变计分）：联课处工委（含「联科处工委」「联课活动处工委」）、文娱工委、XXX志工工委、国际交流筹委 / 负责人。名单、个人页、Excel、CSV 都用金色 ★ 标出，可勾「只看 ★ 特别标记」筛选。

## 四、筹委

- 筹委栏每一条算 1 项（尚待上级回复是否要合并）。
- 从执委栏移过来的见上一节。

## 五、服务时数

- 优先采用学生自填的「总服务时数」；该年没填总数才用逐项相加（上级 2026-09-24 定：只用逐项相加对没逐项写时数的学生不公平）。
- 总服务时数一格里有几个数字时：同一个数字重复写只算一次（例：「总服务时数：168小时」下面又写「1. 168小时」）；「总数 + 细分」只算总数（例：「11h，筹备6h，活动5h」= 11）；分开写校内、校外的相加。
- 被排除（不计）的服务条目会扣除其时数。运动会服务、毕联会相关服务照算。
- 小时、分钟、「50M」等写法都认得。两种算法相差超过 1 小时时，个人页会一并列出供对照。

## 六、比赛与获奖

- 比赛须代表本学会；与所属学会无关的个人比赛不计（例：舞蹈团学生的武术比赛）。按 `award.json` 的学会关键词自动判断，判断不了的标「待确认」暂时计入，可在个人页手动改。
- 同一年同一比赛写在两个学会 → 只计一次，保留与比赛相关的学会（例：舞蹈 & 口才 → 只算舞蹈）。同一学会同一年校外、校内两栏都写了同一条 → 只计一次。
- 以年为单位：每年各自计算，去年写过的比赛今年照算；同一学会同一栏里重复出现的项目（例：不同比赛底下都写「自选南棍—第一名」）各自计算。
- 获奖 ★：比赛条目含名次 / 奖项字眼（冠军、金奖、优秀奖、第X名、特优、佳作，马来文 Johan / Naib Johan 等）即计为获奖（自动识别）。「Championship」「Kejohanan」只是比赛名称，不算获奖；「参与奖」「Participation」「奖项未公布」不算。

## 七、资料总览（按学校评审 Google 表格的格式）

- 栏位：序、学号、班级、姓名，然后每个年份一组：执委（数量）、中层管理（数量）、筹委（数量）、服务（小时）、活动/工作/比赛。数字已套用「计入 / 不计」。
- 年份栏（维护者定：自动）：Result 里最新的年份 = 高三，往前推高二、高一、初三、初二、初一、留级；特别标注（例：2022 的「MCO」）跟着年份走。设定在 `config.ini` 的 `[input_sheet]`。
- 那一年没有资料：放 0 并用红色标出；全部年份都没有资料的学生，名字也标红。留级那一栏大部分学生本来就没有，只放 0、不标红。
- **活动/工作/比赛**（维护者 2026-09-28 定），写成例如 `4/6/2`：
  - 活动 = 校内 / 校外活动栏的条数；写「接待」「演出 / 表演 / 演员 / 演奏员 / 工作人员」的改算工作（「观看 / 观摩演出」「演出集训营」「演奏考试」还是活动）。
  - 工作 = 表演 / 演员、服务 / 大扫除、接待 / 交流：团内工作/表演栏 + 校内 / 校外服务栏的条数。
    - 「例常」的不算工作：周会（维护者定；周会上的演出、主持照算）；另预设早操、日常站岗 / 例常、保健室值勤、图书馆轮值、回收、鱼菜共生、仪容检查、每周 / 每月（**待上级确认**）。
    - 同一年同一项工作写了好几次只算 1 个（例：搬椅子 5 次 → 1 个）；写法一样的自动合并，同一类的在 `work.json`「四、同一类算一个」合并（搬 / 排 / 收椅子；大扫除 / 打扫，待上级确认）。
    - 服务时数不等于工作：例常、重复的服务时数照算。
  - 比赛 = 校内 / 校外比赛栏的条数（参加就算，不只获奖）。
- 可「复制全部」「只复制数字」贴到 Google 表格（贴之前把活动/工作/比赛那几栏设成「纯文本」，免得 4/6/2 变成日期），或下载同样格式的 Excel。

## 八、仍待确认

1. 「二线执委--制服股」算不算中层管理。
2. 校内服务以外栏目的教师节条目怎么算。
3. 执委(A,B) 算 2；筹委每条计 1 项。
4. 「工作」的例常清单（周会以外）和「大扫除 / 打扫」合并。
5. 活动栏的「交流」要不要也算工作（目前算活动）。
6. 比赛目前一行算一个：先写比赛名称、下面再列项目的，名称那一行也会算一个。
