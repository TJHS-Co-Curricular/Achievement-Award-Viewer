怎么用

  • 查人：在搜索框输入姓名、学号、英文名，或任何履历内容（例如「冠军」「新生营」），列表即时筛选。点任一行打开完整履历，按年份分组；「简单 / 详细」可切换，「详细」列出每一条原文和不计的原因。
  • 排序：点表头即可排序，例如按「服务时数」「获奖」从高到低。
  • 对比：勾选最左边的方格（最多 4 人），底部出现「对比」按钮，可并排比较。
  • 按年份看：「全部年份」下拉可只统计某一年（如只看高三 2026）。
  • 资料总览：按学校评审 Google 表格的格式排好每位学生每一年的执委、中层管理、筹委、服务（小时）、活动/工作/比赛。「复制全部」或「只复制数字」可直接贴到 Google 表格（贴之前把活动/工作/比赛那几栏设成「纯文本」，免得 4/6/2 变成日期），也可以下载 Excel。那一年没有资料的格子放 0 并标红。
  • 计入 / 不计：自动判断有误时，在个人页「详细」点条目右边的「计入 / 不计」即可修改，所有数字（含资料总览、Excel）都会跟着改。网站版自动存进程序旁边的 data\成就奖_手动调整.json；离线版存在这台电脑的浏览器里，可用「导出手动调整 / 导入手动调整」交给其他老师。
  • 更新资料：用 Achievement-Award-Viewer.exe（或 python app.py）打开时，网页会自动载入 Result 文件夹的最新内容：新增、修改或删除履历表后几秒内自动更新；改了 config 文件夹里的规则也会自动重算。「导出离线版」得到的单一 HTML 文件内容固定在导出当时。

数字怎么算

完整规则见 Docs\成就奖计分规则.md；实际的判断设定在 config 文件夹的 member_rules.json（职位）、award.json（比赛）、work.json（工作）。

  • 不计的内容（个人页以灰色划线显示并注明原因，所有数字都不含它们）：
    1. 以班级为单位的内容、服务、活动、比赛（含班级歌曲比赛；运动会写生、号码布设计、短片制作比赛也属班级活动）。以学会身份筹办班级赛的「筹委」「团内工作」照算。
    2. B 类（体育、学术培训队）整年不计；只计 A、C、D、E 类。
    3. 高三毕联会 / 高三年级组的职位和筹委（含编辑工委会、广告工委会、教师节工委会）；相关服务、活动照算。
    4. 感恩聚会；学会在运动会上的义卖（演出和服务照算）；教师节相关的校内服务；模范学长、教师节演出负责人、《校讯》主编。
    5. 比赛必须代表本学会：与所属学会无关的个人比赛不计（例如舞蹈团学生的武术比赛）。按学会关键词自动判断；判断不了的标「待确认」，暂时计入。
    6. 同一年同一比赛写在两个学会只计一次，保留与比赛相关的学会。
  • 执委/职务：按手册统一写法。标准职称：主席、秘书、事务（「事物」「总务」同）、财政（正/副）、查账、总学长（正/副）、助理总学长、执委；其它职位写成「执委(XXX,XXX)」（计入其中的职位个数）。没写正/副的当作「正」。合唱团「音乐主席」、二十四节令鼓队的队长类、例常活动主席与执委主席同级。联课处工委归入执委(…)。
  • 中层管理（另计，不算进职务数）：助理类、授课人类、队长类（节令鼓队长除外）、监督/督导/顾问/教练/领队类、首席/组长/领养人类、家族职位、联课组别、校内服务负责人（「校内服务负责人：A、B」每项各算 1 个）、小队常委、体能关主、口令员、堂主、制服负责人、课务股、队伍管理、师傅等。
  • 会员（不计职务数，同年已有其它职位时不另列）：分团职位、学警职衔、XX培训、实习学长、单写「学长」。
  • 筹委：筹委栏每条算 1 项。写在执委栏的活动筹委团职位（如「《弈德杯》筹委主席」）、「监督 / 督导XX主席」、运动会 / 田径赛的职位、执委栏里的演出和公演工委、交流志工团职位都移到筹委（页面标「原写在执委栏」）。
  • 服务时数：优先采用学生自己填写的「总服务时数」（同一个数字重复写只算一次；「总数 + 细分」只算总数）；该年没填总数时，才把校内、校外服务每一项的时数相加。被排除或手动设为不计的服务项，会从中扣除它的时数。两种算法相差超过 1 小时时，个人页会一并列出。
  • 获奖 ★：比赛条目中出现名次或奖项字眼（冠军、金奖、优秀奖、第X名、特优、佳作等）即计为获奖，属自动识别，请以履历原文为准。比赛以年为单位，每年各自计算。
  • 活动/工作/比赛（资料总览）：活动 = 活动栏条数；工作 = 团内工作/表演栏 + 服务栏的条数，包括表演、演员、大扫除、接待、交流；「例常」的（如周会）不算工作，同一年同一项工作写几次只算 1 个（服务时数照算）；活动栏写「接待」「演出 / 表演」的改算工作；比赛 = 比赛栏条数（参加就算）。个人页「详细」会在条目旁标出「例常，不算工作」等原因。
  • ★ 特别标记：联课处工委、文娱工委、XXX志工工委、国际交流筹委/负责人用金色 ★ 标出，只做标记，不改变计分。
  • 同一学号有多个文件时，采用内容最多的一份，其他文件名列在个人页底部。
